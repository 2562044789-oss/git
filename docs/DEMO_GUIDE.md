# 答辩演示流程

## 演示前准备

1. 启动后端，确认移动端预览和管理后台均可打开。
2. 使用手机视口打开移动端预览。
3. 管理后台使用 `admin / admin123` 登录。

## 小程序演示

1. 首页展示社区公告、服务分类和附近急单。
2. 进入任务大厅，按分类和报酬排序。
3. 打开“帮忙取一下丰巢快递”，演示未认证账号接单被拦截的提示。
4. 进入“我的 → 接单员认证”，演示提交实名资料（身份证号 + 手机号 + 证件照片）。
5. 说明接单接口使用条件更新和事务，避免多人重复接单。
6. 发布任务时说明报酬进入平台托管，完成后才结算。
7. 在个人中心展示余额、消息、地址、评价和投诉入口。

## 接单员认证演示

演示数据已预置三种状态，无需现场走完整流程：

1. 用演示账号“林小满”登录，打开任一任务 → 点击接单会被拦截，
   提示“你还没有接单员认证，请先提交实名认证申请”，并给出“去认证”入口。
2. 进入“我的 → 接单员认证”，说明认证三步：提交实名资料 → 管理员审核 → 缴纳 ¥50 保证金。
3. 说明身份证号按 GB 11643-1999 校验、同一号码只能绑定一个账号、
   接口返回一律脱敏、完整号码仅超级管理员可查看且会留痕。
4. 演示“周小北”处于待审核状态，管理员后台审核通过后即可缴纳保证金。
5. 演示“李师傅”已认证、保证金托管中，可以正常接单。
6. 演示退出接单员：需先结清进行中的订单，退出后保证金原路退回钱包余额。

## 管理后台演示

1. 仪表盘展示用户、任务、订单、交易额、待处理投诉和接单员认证统计。
2. 接单员审核：查看脱敏列表 → 查看完整身份证号（提示本次查看已记录日志）→ 通过 / 驳回并填写意见。
3. 用户管理演示禁用账号。
4. 任务管理演示违规任务下架。
5. 分类管理演示启停分类。
6. 投诉处理演示填写处理结论，双方在消息中心收到结果。
7. 公告管理演示发布社区公告，移动端首页同步展示。
8. 操作日志中可看到 `view_id_card`（查看证件）等敏感操作留痕。

## 设计说明

品牌主色为浅绿色 `#46A46F`，背景使用低饱和浅绿灰，重要金额使用暖橙色，投诉和禁用等风险状态使用红色。页面以任务卡片、状态标签、路线时间线和底部操作栏构成主要交互层级。
